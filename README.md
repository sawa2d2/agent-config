# agent-config

## Install

```bash
cd agent-config
bash ./install
```

The installer deploys:

```text
~/
├── .bob/
│   ├── rules/
│   │   └── karpathy.md
│   └── skills/
│       ├── grill-me/
│       ├── grill-with-docs/
│       ├── grilling/
│       ├── domain-modeling/
│       ├── brainstorming/       # Superpowers (example)
│       └── .../
├── .claude/
│   ├── rules/
│   │   └── karpathy.md
│   ├── skills/
│   │   ├── grill-me/
│   │   ├── grill-with-docs/
│   │   ├── grilling/
│   │   └── domain-modeling/
│   └── plugins/                 # Superpowers + Ralph Loop (official)
│       └── .../
└── .local/
    └── bin/
        └── specify             # Spec Kit (uv default)
```
